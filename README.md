# 🚀 React.js Developer Portfolio

Welcome to my personal developer portfolio website. This project showcases my technical skills, featured web applications, and professional services as a React Developer & UI/UX Enthusiast based in San Francisco, CA.

---

## ✨ Features

- **Modern Hero Section:** Catchy introduction with dynamic stats (Experience, Projects Completed, Client Satisfaction).
- **About Me:** A deep dive into my development philosophy, commit history, and core values (Clean Code & High Performance).
- **Interactive Tech Stack:** Visual display of my core frontend and backend expertise.
- **Detailed Skill Metrics:** Clean progress bars illustrating proficiency levels across tools and frameworks.
- **Featured Projects Showcase:** Carousel/Grid layout showcasing real-world applications with metrics and direct access to live demos and source code.
- **Services Offered:** Clear breakdown of professional services from Frontend Development to Performance Optimization.
- **Fully Functional Contact Form:** Built-in validation allowing seamless communication for potential clients and teams.

---

## 🛠️ Tech Stack & Skills

### **Frontend Development**
- **Core:** React.js, Next.js, TypeScript, JavaScript (ES6+)
- **Styling:** Tailwind CSS, Modern CSS frameworks, Responsive Web Design
- **Build Tools:** Vite, CSS Modules

### **Backend & Tools**
- **Backend/Database:** Node.js, REST APIs, MongoDB, Firebase
- **Workflow & Design:** Git & GitHub, Figma
